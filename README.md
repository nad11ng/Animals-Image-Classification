# Animals Image Classification (CNN from Scratch)

A PyTorch image classification project for classifying animals into 10 categories.

This project builds a Convolutional Neural Network (CNN) from scratch to classify food images.

The main goal is to understand how CNN works without using transfer learning.

## Classes

- Butterfly
- Cat
- Chicken
- Cow
- Dog
- Elephant
- Horse
- Sheep
- Spider
- Squirrel

## Project structure

- `src/dataset.py`: dataset and image transformations
- `src/model.py`: CNN architecture
- `src/train.py`: model training
- `src/evaluate.py`: test-set evaluation
- `src/inference.py`: prediction for a single image

## Dataset

The local dataset is stored in `image_data/` and is not included in
the Git repository.
